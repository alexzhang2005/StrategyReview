**版本**: v1.0

**状态**: 开发中

---

## 1. 产品概述

### 1.1 产品名称
StrategyReview — A股策略复盘平台

### 1.2 产品定位
面向个人投资者的 A 股量化辅助工具，整合每日市场复盘与多维度选股策略，实现数据共享、自动更新、历史存档。

### 1.3 核心价值
- **数据共享**：一次更新，全站同步，策略与复盘相互关联
- **自动化**：每日 18:00 自动拉取行情数据，无需手动操作
- **长期存档**：所有历史复盘永久保留，可追溯趋势
- **零成本部署**：完全基于 Cloudflare 免费套餐 + GitHub 免费仓库

## 3. 功能需求

### 3.1 首页（Homepage）

**功能：**
- 展示今日/最新复盘摘要
- 策略池统计数据（命中数量）
- 快速入口：查看完整复盘 / 选股策略 / 上传文件
- 最近 7 天复盘列表

**数据依赖：**
- 最新 `daily_reviews` 记录
- `stocks` 表汇总统计

---

### 3.2 每日复盘（Daily Review）

**功能：**
- 列表页：显示所有历史复盘日期（分页），最新在前
- 详情页：完整展示当日复盘内容
  - 四大指数（上证、深证、创业板、科创50）涨跌幅 + 成交额
  - 情绪统计：涨停家数、跌停家数、上涨比例、总成交额
  - 高阶指标：250日新高新低差、5日差值、MA5比例（含迷你折线图）
  - TOP5 热点板块 + 成分股（标注策略命中）
  - 市场分析文字（手动添加）

**自动更新机制：**
- 每日 18:00（CST / UTC+8）自动触发
- 调用 九宽量化 API（`https://9quant.online`）
- 更新状态：
  - `published`：数据完整，显示"✅ 数据更新完成"
  - `partial`：部分数据获取失败，显示"⚠️ 部分更新"
  - `draft`：尚未更新，显示"⏳ 数据还未更新"
  - `failed`：API 请求全部失败，显示"❌ 数据获取失败"

### 3.3 选股策略（Strategy）

**功能：**
- 策略总览页：4 个策略 + 三合一的命中数量、最后更新时间
- 各策略详情页：
  - 持股增长（S1）：十大股东三连增持
  - 盈利质量（S2）：ROE/毛利/净利三年递增
  - 全速前进（S3）：扣非净利+营收双加速
  - 机构持股增长（S4）：机构三连增持（待数据）
  - 三合一（ALL）：S1+S2+S3 同时命中
- 股票可排序（按代码/名称/行业等）
- 策略标签彩色显示

**数据来源：**
- `stocks` 表（由季度 Excel 上传更新）

**策略计算规则（完整见 `docs/STRATEGY.md`）：**
- S1: Δ26Q1 > 100万股 且 Δ25Q4 > 100万股 且 Δ25Q3 > 0
- S2: ROE25>ROE24>ROE23>0 且 毛利率三年递增 且 扣非净利三年递增
- S3: 扣非净利增速加速(>0) 且 营收增速加速(>0)
- 三合一: S1=True AND S2=True AND S3=True

---

### 3.4 股票详情（Stock Detail）

**功能：**
- 通过代码查询单只股票
- 展示内容：
  - 代码、名称、行业
  - 策略命中标签（彩色）
  - S1 数据：六期十大股东持股 + 三季增量
  - S2 数据：ROE/毛利/扣非净利（25年~22年）
  - S3 数据：扣非净利/营收增速数据

---

### 3.5 选股列表（Selection）

**功能：**
- 上传日度选股 Excel（支持格式：.xls, .xlsx）
- 解析规则：提取第1列（股票代码）和第2列（股票名称）
- 与策略数据库比对，标注命中的策略
- 展示结果：代码、名称、涨幅（当日市场数据）、命中策略、概念
- 点击名称查看股票详情
- 历史上传记录保留

---

### 3.6 管理页面（Admin）

**功能：**
- 上传季度财报 Excel（触发策略数据库重建）
- 上传日度选股 Excel
- 手动触发今日复盘更新
- 查看系统状态

## 4. 非功能需求

### 4.1 性能
- 首页加载 < 3s
- 策略列表（5000 条）加载 < 2s
- API 响应 < 1s

### 4.2 可用性
- 基于 Cloudflare 全球 CDN，99.9% 可用性
- 自动日更新失败时保留前一日数据

### 4.3 成本
- 完全使用免费套餐
  - Cloudflare Pages: 免费（无限请求）
  - Cloudflare Workers: 免费（10万次/天）
  - Cloudflare D1: 免费（5GB，500万读/天）
  - GitHub: 免费（公开仓库）

### 4.4 安全
- 管理接口使用 API Key 认证（Worker Secret）
- 所有上传文件仅在内存中处理，不持久存储原始文件
- API Key 不暴露在前端代码中
